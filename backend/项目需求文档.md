# 课题组资产管理系统 - 需求文档

## 1. 项目概述

### 1.1 项目名称
- **中文名**：课题组资产管理系统
- **英文名**：Lab Asset Management (LAM)

### 1.2 项目背景
课题组在日常科研工作中需要管理大量的仪器设备、试剂耗材等资产。传统的手工管理方式效率低下，容易出现资产丢失、库存不足、采购混乱等问题。本系统旨在通过信息化手段，实现资产的全生命周期管理，提高管理效率，降低管理成本。

### 1.3 项目目标
- 实现资产信息的数字化管理
- 规范资产采购、借用、领用流程
- 实时监控库存状态，避免物资短缺
- 提供数据统计分析，辅助决策
- 简化操作流程，提升用户体验

### 1.4 技术架构
- **后端框架**：Flask 3.0+
- **数据库**：MySQL 8.0+
- **前端技术**：React 18+ + Ant Design
- **认证系统**：JWT (JSON Web Token)
- **API设计**：RESTful API
- **部署方式**：Docker 容器化部署

## 3. 功能需求

### 3.1 用户认证模块

#### 3.1.1 用户注册
- **功能描述**：新用户可以注册账号
- **输入字段**：
  - 用户名（必填，唯一）
  - 密码（必填，需确认）
  - 邮箱（可选）
- **业务规则**：
  - 用户名不能重复
  - 密码需符合安全要求
  - 注册成功后自动登录

#### 3.1.2 用户登录
- **功能描述**：已注册用户登录系统
- **输入字段**：
  - 用户名（必填）
  - 密码（必填）
- **业务规则**：
  - 验证用户名和密码
  - 登录成功后跳转到仪表盘

#### 3.1.3 用户登出
- **功能描述**：用户退出系统
- **业务规则**：
  - 清除会话信息
  - 跳转到首页

### 3.2 资产管理模块

#### 3.2.1 资产列表
- **功能描述**：查看所有资产信息
- **显示字段**：
  - 资产编号
  - 资产名称
  - 资产类别
  - 状态（可用/使用中/维修中/已报废）
  - 存放位置
  - 保管人
  - 采购日期
  - 采购价格
- **筛选功能**：
  - 按类别筛选
  - 按状态筛选
- **排序**：按创建时间倒序

#### 3.2.2 添加资产
- **功能描述**：管理员添加新资产
- **输入字段**：
  - 资产类型（仪器/试剂/耗材/其他）
  - 资产名称（必填）
  - 资产编号（自动生成或手动输入）
  - 资产类别（必填）
  - 供应商（可选）
  - 规格参数（可选）
  - 采购日期（可选）
  - 采购价格（可选）
  - 存放位置（可选）
  - 保管人（可选）
  - 备注（可选）
- **业务规则**：
  - 资产编号必须唯一
  - 默认状态为"可用"
  - 耗材类型需要填写单位、库存、最低库存、单价

#### 3.2.3 资产状态管理
- **状态类型**：
  - `available` - 可用
  - `in_use` - 使用中
  - `maintenance` - 维修中
  - `retired` - 已报废
- **状态转换规则**：
  - 可用 → 使用中：资产被借用时
  - 使用中 → 可用：资产被归还时
  - 任何状态 → 维修中：管理员手动设置
  - 任何状态 → 已报废：管理员手动设置

### 3.3 耗材管理模块

#### 3.3.1 耗材列表
- **功能描述**：查看所有耗材信息
- **显示字段**：
  - 耗材编号
  - 耗材名称
  - 类别
  - 单位
  - 当前库存
  - 最低库存
  - 单价
  - 存放位置
- **筛选功能**：
  - 按类别筛选
  - 按低库存筛选（库存 < 最低库存）
- **预警提示**：
  - 库存低于最低库存时显示警告

#### 3.3.2 添加耗材
- **功能描述**：管理员添加新耗材
- **输入字段**：
  - 耗材名称（必填）
  - 耗材编号（自动生成）
  - 类别（必填）
  - 供应商（可选）
  - 单位（默认"个"）
  - 初始库存（默认0）
  - 最低库存（默认10）
  - 单价（可选）
  - 存放位置（可选）
- **业务规则**：
  - 耗材编号自动生成格式：CON-XXXX
  - 库存低于最低库存时需要预警

### 3.4 采购管理模块

#### 3.4.1 采购申请
- **功能描述**：用户提交采购申请
- **输入字段**：
  - 采购标题（必填）
  - 物品名称（必填）
  - 数量（必填，默认1）
  - 预算（必填）
  - 供应商（可选）
  - 采购原因（必填）
- **业务规则**：
  - 申请提交后状态为"待审批"
  - 记录申请人和申请时间
  - 记录操作日志

#### 3.4.2 采购审批
- **功能描述**：管理员审批采购申请
- **审批操作**：
  - 批准：状态改为"已审批"，记录审批人和审批时间
  - 拒绝：状态改为"已拒绝"，记录审批人
- **审批列表**：
  - 待审批列表
  - 已批准列表（最近10条）
  - 已拒绝列表（最近10条）

#### 3.4.3 我的采购申请
- **功能描述**：用户查看自己的采购申请记录
- **显示信息**：
  - 申请标题
  - 物品名称
  - 数量
  - 预算
  - 状态
  - 申请时间
  - 审批人（如已审批）

### 3.5 资产借用模块

#### 3.5.1 借用申请
- **功能描述**：用户借用可用资产
- **输入字段**：
  - 选择资产（仅显示可用状态的资产）
  - 用途（可选）
- **业务规则**：
  - 只能借用状态为"可用"的资产
  - 借用成功后资产状态改为"使用中"
  - 创建借用记录
  - 记录操作日志

#### 3.5.2 归还资产
- **功能描述**：用户归还已借用的资产
- **业务规则**：
  - 只能归还自己借用的资产
  - 归还成功后资产状态改为"可用"
  - 更新借用记录的归还日期和状态
  - 记录操作日志

#### 3.5.3 我的借用记录
- **功能描述**：用户查看自己的借用记录
- **显示信息**：
  - 资产名称
  - 借用日期
  - 归还日期（如已归还）
  - 用途
  - 状态（借用中/已归还）

### 3.6 领料管理模块

#### 3.6.1 领料申请
- **功能描述**：用户申请领用耗材
- **输入字段**：
  - 选择耗材（仅显示库存>0的耗材）
  - 领用数量（必填）
  - 用途（可选）
- **业务规则**：
  - 申请提交后状态为"待审批"
  - 不立即扣减库存，等待审批
  - 记录申请人和申请时间

#### 3.6.2 领料审批
- **功能描述**：管理员审批领料申请
- **审批操作**：
  - 批准：
    - 检查库存是否充足
    - 扣减库存
    - 状态改为"已批准"
    - 记录审批人和审批时间
  - 拒绝：
    - 状态改为"已拒绝"
    - 记录审批人
- **业务规则**：
  - 库存不足时不能批准
  - 显示当前库存信息

#### 3.6.3 我的领料记录
- **功能描述**：用户查看自己的领料记录
- **显示信息**：
  - 物品名称
  - 领用数量
  - 用途
  - 状态（待审批/已批准/已拒绝）
  - 申请时间
  - 审批人（如已审批）

### 3.7 资产转移模块

#### 3.7.3 我的转移申请

## 5. 业务流程

### 5.1 资产借用流程
```
用户登录 → 查看可用资产 → 选择资产并填写用途 → 提交借用申请 
→ 系统自动批准 → 资产状态改为"使用中" → 创建借用记录 
→ 使用完毕 → 用户归还资产 → 资产状态改为"可用" → 更新借用记录
```

### 5.2 采购申请流程
```
用户登录 → 填写采购申请信息 → 提交申请 → 状态为"待审批"
→ 管理员审批 → 
  ├─ 批准：状态改为"已审批"，记录审批人和时间
  └─ 拒绝：状态改为"已拒绝"，记录审批人
→ 用户查看审批结果
```

### 5.3 领料申请流程
```
用户登录 → 选择耗材并填写数量和用途 → 提交申请 → 状态为"待审批"
→ 管理员审批 → 
  ├─ 批准：检查库存 → 扣减库存 → 状态改为"已批准"
  └─ 拒绝：状态改为"已拒绝"
→ 用户查看审批结果
```

### 5.4 资产转移流程
```
用户登录 → 选择资产并填写新位置和原因 → 提交申请 → 状态为"待审批"
→ 管理员审批 → 
  ├─ 批准：更新资产位置 → 状态改为"已批准"
  └─ 拒绝：状态改为"已拒绝"
→ 用户查看审批结果
```
